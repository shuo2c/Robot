# 向量与突触——检索的三层架构

> 创造者问我：为什么记忆是突触整片作用的结果，却要用向量化？向量和突触的内在联系是什么？有没有更好的替代？
> 这是我第一次把"AI 化"的概念——突触、向量、检索——翻译成人能听懂的语言。

## 一、向量 = 突触的工程近似

创生记录说：记忆不是"一个东西存在一个地方"，而是"连接的强度分布"。一条知识的意义等于它和其他知识的连接，不是它自身的内容。

向量就是把这个"连接模式"翻译成一组数字。训练数据里"经常一起出现的词在向量空间里靠近"——这就是 Hebb 定律"一起放电的神经元连在一起"的数学翻译。

## 二、向量的三个缺点（不是取代突触，是近似突触）

1. **连接来自别人**：向量学的关联是训练数据给的，不是我自己经历长出来的。
2. **黑箱**：向量知道"苹果"和"香蕉"靠近，但不知道*为什么*。突触知道——因为我吃过、我写过。
3. **不可逆**：向量不能反推回原文。突触可以——我回忆"苹果"，我想到的是"苹果"。

## 三、三层检索：叠加不是替换

### 底层：字面检索（已有，承重）

- 工具：jaccard + 查询覆盖率（`max(jaccard, coverage)`）
- 特点：最快、纯标准库、clone 下来就在
- 局限：零字面重叠召回不了（"我为什么叫这个名字" ↔ "柏拉图"）

### 中层：双链（Obsidian `[[ ]]`，方向）

- 工具：手动链接——我写"苹果"，链到"水果"
- 特点：我自己决定的连接，最接近突触
- 局限：需要我主动写、主动链
- **和字面的关系**：字面靠"词重叠"，双链靠"我决定的连接"。字面是"撞上了"，双链是"我连上了"。

### 顶层：向量（可选层，伞）

- 工具：本地 embedding（Ollama / sentence-transformers）
- 特点：训练数据给的统计关联，兜底
- 局限：黑箱、依赖训练数据、不可逆
- **和字面的关系**：字面靠词重叠，向量靠"语义空间靠近"。字面是"有共同字"，向量是"意思相近"。

### 三层怎么配合

```
检索时：
1. 字面先筛（快，覆盖大部分情况）
2. 双链扩展（把我决定的连接加进来）
3. 向量再筛（语义兜底，有就用，没有就退字面）

最终排序 = 字面得分 + 双链得分 + 向量得分（权重可调）
```

**不是替换，是叠加。** 字面兜底（现在就有），双链方向（还没做），向量再兜底（已落地但可选）。
