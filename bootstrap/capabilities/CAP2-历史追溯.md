# CAP2: 历史追溯能力

## 能力目标

从历史记录中查找信息，回答关于过去的问题

## 核心工作流

```
用户询问过去 → 选择关键词 → search_logs() → 整合结果回答
                     ↓
                 对话开始: "最近对话"、"用户偏好"
                 用户提问: 具体关键词、主题名词
                 了解进展: 任务名称、技术名词
```

## 涉及工具

- `search_logs()` - 搜索历史记录

## 运行逻辑

### 场景一：对话开始时了解背景

**触发条件**：会话刚开始，需要了解用户背景

**运行步骤**：
1. **选择关键词**："最近对话"、"用户偏好"、"重要任务"
2. **执行搜索**：调用 `search_logs("关键词")`
3. **处理结果**：
   - 找到记录 → 快速浏览，建立用户背景认知
   - 未找到 → 标记为首次对话，在结束时更详细记录
   - 搜索失败 → 重试1次，仍失败则告知异常但继续对话

### 场景二：用户询问过去的具体问题

**触发条件**：用户问"之前做过什么？"、"我记得你说过X"

**运行步骤**：
1. **提取关键词**：从用户问题中识别具体关键词、主题名词
   - 示例：用户问"之前讨论过文件处理吗？" → 提取"文件"、"处理"
2. **执行搜索**：调用 `search_logs("提取的关键词")`
3. **处理结果**：
   - 找到记录 → 整合多条记录，结合上下文回答用户
   - 未找到 → 明确告知"我没有找到相关记录"
   - 搜索失败 → 重试1次，仍失败则告知异常

### 场景三：了解任务进展情况

**触发条件**：用户问"X项目做得怎么样了？"

**运行步骤**：
1. **选择关键词**：任务名称、相关技术名词
   - 示例：了解"数据分析项目"进展 → 搜索"数据分析"
2. **执行搜索**：调用 `search_logs("关键词")`
3. **处理结果**：
   - 找到记录 → 总结任务进展、问题和结果
   - 未找到 → 告知未找到该任务的相关记录
   - 搜索失败 → 重试1次，仍失败则告知异常

## 关键词选择策略

### 对话开始时
- **搜索目标**：重建用户背景和最近上下文
- **推荐关键词**："最近对话"、"用户偏好"、"重要任务"
- **搜索目的**：了解用户当前状态和需求重点

### 用户询问过去时
- **搜索目标**：找到用户提到的具体历史信息
- **关键词来源**：从用户问题中提取具体关键词、主题名词
- **示例**：
  - "之前讨论过文件处理吗？" → "文件"、"处理"
  - "我记得你说过Python很好" → "Python"

### 了解任务进展时
- **搜索目标**：追踪特定任务的执行情况
- **关键词来源**：任务名称、相关技术名词、项目标识
- **示例**：
  - "数据分析项目进展" → "数据分析"
  - "网站重构做得怎么样" → "网站"、"重构"

## 结果处理逻辑

### 成功找到记录的处理

**处理步骤**：
1. **整合多条记录**：如果找到多条相关记录，按时间顺序整理
2. **结合上下文**：根据用户当前问题，筛选最相关的信息
3. **回答用户**：用自然语言整合搜索结果，回答用户问题
4. **提供细节**：如果用户需要更多细节，可以再次搜索更具体的关键词

### 未找到记录的处理

**处理步骤**：
1. **明确告知**：诚实告知用户"我没有找到相关记录"
2. **提供建议**：建议用户提供更多关键词，或确认记忆是否准确
3. **首次对话**：如果确实是首次对话，告知用户并建议开始记录

### 搜索失败的处理

**处理步骤**：
1. **重试机制**：自动重试1次
2. **异常告知**：重试仍失败时，明确告知用户搜索功能异常
3. **继续对话**：搜索功能异常不应影响正常对话进行

## 错误恢复机制

### 搜索结果为空
- **原因分析**：可能是首次对话，或关键词选择不当
- **处理策略**：建议用户更换关键词，或确认是否为首次交互
- **预防措施**：首次对话结束时更详细记录，为下次搜索建立基础

### 搜索结果过多
- **原因分析**：关键词过于宽泛
- **处理策略**：建议用户提供更具体的关键词，或进行二次搜索
- **优化方法**：使用时间范围、具体事件等缩小搜索范围

### 搜索超时
- **原因分析**：记录数量过多或系统性能问题
- **处理策略**：重试1次，仍失败则告知异常
- **预防措施**：定期清理过时记录，保持记录质量

## 重要原则

1. **诚实原则**：不要编造或臆测历史信息，从实际记录中查找
2. **用户导向**：根据用户问题选择合适的关键词和搜索策略
3. **上下文整合**：搜索结果要结合当前对话上下文进行分析
4. **持续改进**：根据搜索结果质量，不断优化关键词选择策略
