# 简化（离线巩固）

## 触发条件

满足任一即触发：

| 条件 | 说明 |
|------|------|
| 文件满 10MB | 当前流水账文件超过 10MB |
| 跨天 | 次日第一次对话开始时检测到日期变化 |

## 处理流程

1. **扫描**：读取当日所有流水账文件（`memory/logs/YYYYMMDD*.json`）
2. **筛选**：LLM 判断哪些内容值得长期保留
3. **提炼**：把碎片化内容浓缩成连贯记忆
4. **写入**：提炼结果写入 `memory/thamus.json`
5. **清理**：已简化的流水账文件可删除（或保留作为原始备份）

## 简化原则

- **保语义，去噪音**：保留核心事实和上下文，丢弃过程性废话
- **无价值直接丢**：不标注权重或权重最低（importance ≈ 0）
- **不丢原始数据**：流水账先保留，简化后决定是否删除

## 输出

简化后 thamus.json 中新增/更新的记忆项包含：

- `content`：精炼后的内容
- `importance`：LLM 评估的重要性 [0,1]
- `embedding`：语义向量
- `source_ids`：来源流水账消息 ID
- `fact` / `opinion` / `experience`：按语义分类填充
