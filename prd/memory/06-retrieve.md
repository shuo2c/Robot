# 检索机制

## 检索范围

所有日志文件（`memory/logs/`）都是记忆存储，检索时扫描所有文件。

## 双路检索

| 方式 | 说明 |
|------|------|
| **BM25** | 关键词匹配，适合精确搜索 |
| **向量相似度** | embedding 余弦距离，适合语义搜索 |

## 检索流程

1. 用户提问 → 提取 query
2. **BM25 搜索**：匹配关键词
3. **向量搜索**：匹配语义
4. **合并排序**：BM25 分 + 向量分，取 top-k
5. 返回结果

## 参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| Top-K | 10 | 返回条数上限 |
| 相似度截断 | 0.65 | 低于此值不返回 |
| BM25 权重 | 0.5 | 与向量分各占一半 |

## cold 排除

`state = "cold"` 的记忆不参与检索，除非 top-k 不足。
