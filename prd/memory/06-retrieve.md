# 检索机制

## 语义记忆检索

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 方式 | 向量相似度（余弦距离） | — |
| 权威性加权 | official × 1.2 | personal × 1.0, inferred × 0.8 |
| Top-K | 10 | 返回条数上限 |
| 相似度截断 | 0.65 | 低于此值不返回 |

## 情景记忆检索 — 三层机制

### 第 1 层：字面粗筛（承重）

- 计算 `max(jaccard, 查询覆盖率)` 作为相关性。
- 混合分 = `strength × (0.1 + 相关性)`。
- 取前 `expand_factor`（默认 2k）条作为候选。

### 第 2 层：双链扩展

- 对第 1 层候选的每条记忆，将其 `linked_ids` 中的 active 记忆加入候选集。
- 链入记忆的强度乘以 0.5 作为分数。

### 第 3 层：向量精排（伞）

- 若有 embedding，对候选集计算余弦相似度。
- 混合分 = `0.6 × 字面分 + 0.4 × 向量分`。
- 取 top-k 返回。

### 通用规则

| 规则 | 说明 |
|------|------|
| Chat 优先 | 同等相关性分数下，`modality="chat"` 排在前面 |
| Floor 值 | 0.1，确保强记忆即使不相关也能浮现 |
| Cold 排除 | `state="cold"` 的记忆不参与检索 |
| k 限制 | 默认 5 条 |

## 程序性记忆检索

- 按工具名称检索。
- 返回历史成功率、平均耗时、最近调用时间。
- 成功率最高的工具优先推荐。
