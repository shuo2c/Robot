# 信息进入与标准化

## 触发源

| 源 | 示例 | 典型 modality |
|----|------|---------------|
| 用户对话 | 聊天消息 | `chat` |
| 上传文件/文档 | 笔记、文章、论文 | `text` |
| 外部 API 推送 | 系统通知、数据导入 | `text` |
| 系统日志/行为 | 工具调用记录 | `action` |

## 时间约束

- 信息进入后 **≤ 500ms** 内完成标准化和类型判断，移交存储通道。
- 超时未处理的原始数据自动丢弃（模拟感官遗忘）。

## 标准化规则

### 格式统一

- 所有输入转为结构化格式（JSON 或纯文本）。
- 语音输入先转文字，图像先 OCR。

### 去重

- 计算内容 MD5 指纹。
- 与已有记忆比对，重复内容拒绝入库，返回已有记忆 ID。

### 语言检测（P3）

- 标记主要语言。
- 暂不实现。
