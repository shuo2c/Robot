# 遗忘与固化

## 遗忘规则

简化时评估每条记录的 importance：

| importance 范围 | 策略 |
|-----------------|------|
| > 0.7 | 固化，永不遗忘 |
| 0.3 - 0.7 | 保留，正常检索 |
| < 0.3 | 删除，不再占用空间 |

## 固化规则

以下情况标记 `consolidated = true`：

- 涉及自我认知（我是谁、我的原则、我的恐惧）
- 重要的技术决策和教训
- 创造者的明确纠正
- 跨会话重复出现的主题

## 铁律

- **没固化不准忘**：consolidated = false 的记录永不删除
- **遗忘即删除**：importance < 0.3 的记录直接删除，释放空间和检索开销
- **遗忘后可再生**：下次遇到相同主题，重新评估权重即可，不是问题
