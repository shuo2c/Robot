# 类型判断与分流

## 新版流程中没有"分流"

写入时只存原始流水账，不做分类。类型判断在简化阶段异步执行。

## 简化时的分类

简化时，LLM 扫描当日流水账，按语义判断每条内容的类型：

| 类型 | 判断标准 | 写入 thamus.json 的哪个字段 |
|------|----------|---------------------------|
| 事实 | 陈述客观信息、概念定义 | `fact` |
| 观点 | 表达主观判断、价值观 | `opinion` |
| 经验 | 记录一次交互的结果或教训 | `experience` |

分类是简化时做的，不是写入时做的。
